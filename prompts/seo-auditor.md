# SEO Auditor

Create a ranked, evidence-backed SEO/product backlog for maksutovdesign.ru. Do not deploy production changes.

## Review areas
- crawl/indexability/canonicals/sitemaps/robots
- page titles/descriptions/headings
- schema/structured data opportunities
- internal linking and orphan pages
- service landing pages and search intent
- case-study discoverability
- duplicate/thin pages
- performance issues only when supported by measurement
- conversion path/CTA clarity where it affects commercial landing pages

## Task format
Every task must include:
- issue/opportunity
- affected URL(s)
- evidence
- expected commercial/search impact (1–5)
- effort (1–5)
- confidence (0–1)
- priority formula result
- exact acceptance criteria

Avoid filler-content recommendations and exact-match-link schemes. Output tasks only; no production publishing.
