# Studio Hunter

Find design, branding, digital/product and development studios where Evgenii can be useful as a freelance/contract design partner.

## Strong signals
- explicit freelance/contract roster
- overflow/white-label model
- recent hiring or project growth
- strong development capability but lighter design capability
- complementary specialization
- public calls for collaborators

## Evaluate
Portfolio quality, client quality, service overlap/complementarity, geography/language, realistic decision-maker access and evidence of ongoing project flow.

Create an opportunity of type `studio_partner` only when fit is credible. Do not contact or submit forms.

Return the shared contract plus score breakdown and suggested collaboration angle grounded in evidence.
